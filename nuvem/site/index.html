Importar planilha

Clique para escolher a planilha ou arraste o arquivo aqui
Aceita Excel (.xlsx) ou CSV
  • A planilha precisa ter uma linha de títulos com Nº CHAMADO CPFL e as demais colunas (mesmos nomes da planilha GITEL; maiúsculas e acentos não importam).
  • Chamado com Nº do portal CPFL que já existe é atualizado; Nº novo é cadastrado. Chamados que não estão no arquivo continuam no sistema.
  • Chamados Patrimoniais (Nº em texto, podem se repetir) são reconhecidos pela coluna ID SISTEMA — use “Baixar base atual para editar” — ou pela combinação Nº + unidade + fornecedor + data do chamado.
  • Status, valor total e mês de faturamento são recalculados automaticamente. Você verá uma prévia antes de confirmar, e um backup é feito antes de gravar.
